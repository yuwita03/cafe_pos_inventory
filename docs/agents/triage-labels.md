# Triage labels

| Role            | GitHub label    | Meaning                            |
| --------------- | --------------- | ---------------------------------- |
| needs-triage    | needs-triage    | Needs evaluation                   |
| needs-info      | needs-info      | Waiting for clarification          |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation      |
| wontfix         | wontfix         | Will not be actioned               |

A ready-for-agent label does not override blocking dependencies,
repository approval rules, or instructions to hold implementation.
Preserve existing label definitions when creating missing labels.
